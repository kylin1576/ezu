# 前端 UI 基础知识手册

> 面向不懂设计的前端协作指南：学完能跟 AI 用"内行话"沟通，一次把 UI 需求说清楚。

---

## 一、一个页面由什么组成

```
页面 = 布局(骨架) + 组件(器官) + 颜色(皮肤) + 文字 + 交互
```

| 概念 | 是什么 | 类比 |
|---|---|---|
| HTML | 内容和结构 | 房子的框架 |
| CSS | 样式：颜色、大小、位置 | 装修 |
| 组件 | 现成的积木：按钮、卡片、弹窗 | 宜家家具 |
| 图标/图片 | 素材 | 软装 |

---

## 二、布局：页面怎么摆

### 1. 先分区，再排内容

任何页面都是先切成大块。App 商城通常是：

```
┌──────────────┐
│  顶部搜索栏    │ ← 固定不动
├──────────────┤
│              │
│  内容滚动区    │ ← 轮播/金刚区/商品流
│              │
├──────────────┤
│ 首页|分类|我的 │ ← 底部Tab，固定
└──────────────┘
```

电脑端后台则是"左侧导航 + 顶部栏 + 右侧内容区"的左右分栏结构。

### 2. 三种基本排列（90% 的布局就是这三种的组合）

| 方式 | 效果 | 例子 |
|---|---|---|
| **纵向堆叠** | 从上往下排 | 手机页面的默认方式 |
| **横向排列** | 从左往右排 | 搜索框 + 旁边一个按钮 |
| **网格** | 行列对齐 | 商品宫格（一行 2 个 / 3 个） |

### 3. 盒模型：理解间距的钥匙

页面上每个东西都是一个"盒子"：

```
┌─ 外边距 margin（我和别人的距离）─┐
│ ┌─ 边框 border ─────────────┐ │
│ │ ┌─ 内边距 padding ──────┐ │ │
│ │ │      内容（文字/图片）   │ │ │
│ │ └──────────────────────┘ │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

跟 AI 说"卡片内边距 16px、卡片之间间距 12px"，说的就是这两层。

### 4. 间距要有节奏

专业设计的间距不是随机的，是 **8 的倍数**：`4 / 8 / 16 / 24 / 32`。

- 相关的东西离得近（8-16px）
- 不相关的离得远（24-32px）
- 这就是"呼吸感"的本质

### 5. 响应式

同一套页面在手机/平板/电脑上自适应：手机上下堆叠，电脑左右分栏。跟 AI 说"做响应式"即可。

## 三、颜色：一套配色怎么定

### 1. 一套配色只需要 4 类颜色

| 角色 | 数量 | 用途 | 商城例子 |
|---|---|---|---|
| **主色** | 1 个 | 按钮、价格、强调 | 京东红 #E93B3D |
| **中性色** | 3-5 档灰 | 文字、边框、背景 | #333 深文字 / #999 浅文字 / #f5f5f5 背景 |
| **功能色** | 4 个 | 固定语义 | 成功绿、警告橙、危险红、链接蓝 |
| **辅色** | 0-2 个 | 点缀、渐变 | 渐变的第二色 |

### 2. 核心法则：60-30-10

- **60%** 中性色（背景、大面积留白）
- **30%** 次要色（卡片、文字）
- **10%** 主色（按钮、价格——只出现在你想让人点/看的地方）

主色越多越廉价，**克制 = 高级感**。

### 3. 颜色怎么写

- 十六进制：`#E93B3D`（AI 都看得懂）
- 也可以说人话："主色用珊瑚红"，AI 会帮你选色值

### 4. 色阶

一个主色会衍生出深浅系列（如 red-50 ~ red-900），用于 hover 加深、浅色背景等。说"hover 时加深一点"AI 就懂。

## 四、文字：层级就是信息优先级

| 元素 | 手机端字号 | 用途 |
|---|---|---|
| 大标题 | 20-24px | 页面标题 |
| 小标题 | 16-17px | 卡片标题 |
| 正文 | 14-15px | 商品名等 |
| 辅助文字 | 12px | "已售3000+" 这类弱信息 |

**技巧**：重要的字大且粗，不重要的字小且灰。一屏至少 3 个层级——全一样大就是"土"的根源。

## 五、组件：你的积木箱

知道名字就能点菜：

| 分类 | 组件 |
|---|---|
| **导航类** | 底部 TabBar、顶部导航栏、面包屑、侧边分类栏 |
| **展示类** | 轮播图 Banner、商品卡片、宫格导航(金刚区)、标签、倒计时 |
| **操作类** | 按钮、悬浮购物车按钮、SKU 规格弹窗 |
| **反馈类** | Toast 轻提示、加载动画、下拉刷新、空状态 |
| **表单类** | 输入框、搜索框、开关、选择器 |

## 六、UI 组件库：让专业的人干专业的事

不要自己描述每个像素，直接指定组件库，AI 会用现成组件拼出商业级质感。

| 库 | 官网 | 适用场景 | 背景 |
|---|---|---|---|
| **Vant** | vant-ui.github.io/vant | 手机端商城（首选） | 有赞出品，天生为电商设计 |
| **NutUI** | nutui.jd.com | 手机端商城 | 京东官方开源 |
| **Ant Design Mobile** | mobile.ant.design | 手机端通用 | 蚂蚁出品 |
| **Ant Design** | ant.design | 电脑端后台管理 | 后台管理系统事实标准 |
| **Element Plus** | element-plus.org | 电脑端后台(Vue) | 国内最流行的 Vue 后台库 |
| **Arco Design** | arco.design | 后台管理 | 字节跳动出品 |

- **Dribbble**（dribbble.com）：设计师作品集，适合找风格方向

## 七、跟 AI 沟通的话术

### 1. 最有效的 3 种提法

**抄网站**：

> "参考 https://ant.design 的风格：大量留白、卡片布局、主色 #1677ff"

**给截图**（AI 能看图）：

> "照这个截图的布局和配色做，内容换成我的"

**感觉词 + 具体落点**：

| 你想要的感觉 | 该这样说 |
|---|---|
| 简洁专业 | "留白多一些，颜色不超过 3 种，主色用蓝色 #1677ff" |
| 科技感 | "深色背景，霓虹蓝点缀，卡片带细边框和微光" |
| 高端 | "黑金配色，大标题，图片占屏 60%" |
| 活泼 | "圆角大一点(12px)，颜色鲜艳，按钮带 hover 动效" |

### 2. 改稿时说"位置 + 改什么"

- ❌ "太丑了，再改改"
- ✅ "顶部导航太挤，菜单间距加大，高度加到 64px"
- ✅ "主色太刺眼，换成 #1677ff，hover 时加深 10%"
- ✅ "卡片间距统一 16px，加个浅阴影"
- ✅ "手机上乱了，列表改成上下堆叠"

### 3. 万能起手式

> "我在做 XXX 系统（一句话说清业务），帮我设计页面。先给我 2~3 版不同风格方案（如：简洁商务风 / 深色科技风 / 轻快活泼风），我看效果再定方向。"

### 4. 需求四步句式（照套即可）

**布局分区 → 组件清单 → 主色 → 间距/圆角**

> ❌ 以前："帮我做个商城首页，好看点"
>
> ✅ 现在："用 Vant 做商城首页：顶部搜索栏，Banner 轮播，下面 8 宫格金刚区，然后秒杀横条（带倒计时），最后商品瀑布流（一行 2 个卡片）。主色 #E93B3D，价格用主色加粗，卡片间距 12px、圆角 8px。"

# 易租（ezu）数据库设计文档

> 版本：v0.1（骨架 + 基础约定）
> 日期：2026-11-10
> 状态：建模阶段主战场，DDL 逐域补充

---

## 1. 基础约定

| 项 | 约定 |
|----|------|
| 表名 | 小写下划线，统一 `t_` 前缀（如 `t_product`、`t_order`） |
| 主键 | `id bigint`，雪花 ID（MyBatis-Plus `ASSIGN_ID`） |
| 审计字段 | 所有业务表带 `create_time / update_time / create_by / update_by / is_deleted` |
| 逻辑删除 | **`0`=未删除，`1`=已删除**（常规语义） |
| 金额 | `decimal(12,2)`，单位元 |
| 状态 | `tinyint` + Java 枚举映射，字段注释标注所有值含义（前端依赖） |
| 时间 | `datetime`，业务日期用 `date` |
| 单号 | 业务单号对外交互（订单号如 `R20261110xxxx`），不暴露数据库 ID |
| 外键 | 不建物理外键，逻辑关联 + 索引 |
| 索引 | 高频查询字段建索引，前缀 `idx_`；唯一索引前缀 `uk_` |

## 2. 表域划分（全景，约 30 张）

| 域 | 表 | 说明 |
|----|-----|------|
| 用户 | `t_user`、`t_user_address` | openid 双端（微信/支付宝）、手机号 |
| 商品 | `t_category`、`t_product`（SPU）、`t_product_sku`、`t_rental_plan`、`t_product_param` | SKU 挂租金方案（日/周/月/季/买断价） |
| 设备资产 | `t_device`（SN 台账）、`t_device_check_report`、`t_device_repair` | SN 绑定 SKU；状态：在库/锁定/在租/维修/报废 |
| 订单 | `t_order`、`t_order_item`、`t_lease`、`t_deposit_record`、`t_bill` | 下单快照冗余；订单锁定 SN；押金/账单流水 |
| 支付 | `t_payment_record` | channel 抽象（mock / alipay 预留） |
| 物流 | `t_logistics` | 发货/归还双向，一单多段 |
| AI | `t_ai_knowledge_doc`、`t_ai_conversation`、`t_ai_message` | 源文档/分段管理；向量存 VectorStore |
| 后台 | `t_admin_user`、`t_role`、`t_admin_user_role`、`t_permission`、`t_role_permission`、`t_operate_log` | 标准 RBAC |

## 3. 核心状态机（建模依据）

### 3.1 订单状态

```
待支付 → 待发货 → 已发货 → 租赁中 → 归还中（用户寄回）→ 验收中 → 已完成
   │        │        │                              │
   └────────┴────────┴──→ 已取消          （验收不通过 → 定损流程【二期】）
```

### 3.2 设备（SN）状态

```
在库 → 锁定（下单未发货）→ 在租 → 归还验收 → 在库
                维修 ──→ 报废（终态）
```

## 4. 核心实体关系（ER 概览）

```
t_category 1 ──── n t_product（SPU）
t_product  1 ──── n t_product_sku
t_product_sku 1 ─ n t_rental_plan（日/周/月/季/买断，多方案）
t_product_sku 1 ─ n t_device（SN，一台一行）
t_user 1 ──── n t_order ──── 1 t_order_item（一期单 SKU，结构仍保留明细表）
t_order_item 1 ─ 1 t_device（订单锁定具体 SN）
t_order 1 ─── n t_lease（初始租期 + 续租段）
t_order 1 ─── n t_deposit_record / t_bill / t_logistics / t_payment_record
t_admin_user n ─ n t_role n ─ n t_permission
```

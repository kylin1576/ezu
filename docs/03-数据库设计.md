# 易租（ezu）数据库设计文档

> 版本：v0.2（建模完成，DDL 待评审）
> 日期：2026-11-10
> 状态：可执行 DDL 已产出至 `sql/建表/`（8 个域文件，26 张表），本文档为设计说明

---

## 1. 基础约定

| 项 | 约定 |
|----|------|
| 表名 | 小写下划线，统一 `t_` 前缀（如 `t_product`、`t_order`） |
| 主键 | `id bigint`，雪花 ID（MyBatis-Plus `ASSIGN_ID`） |
| 审计字段 | 业务表统一带 `create_time / update_time / create_by / update_by / is_deleted`（例外：`t_operate_log` 只增不改，仅 `create_time`） |
| 逻辑删除 | **`0`=未删除，`1`=已删除**（常规语义；DB 默认值兜底 + MyBatis-Plus 全局配置） |
| 金额 | `decimal(12,2)`，单位元 |
| 状态 | `tinyint` + Java 枚举映射，字段注释标注所有值含义（前端依赖） |
| 时间 | 时间点 `datetime`，业务日期 `date` |
| 外键 | 不建物理外键，逻辑关联 + 索引（`idx_` 前缀；唯一索引 `uk_` 前缀） |
| 字符集 | `utf8mb4 / utf8mb4_general_ci` |

## 3. 核心状态机（建模依据）

### 3.1 订单状态（t_order.status）

```
待支付(10) → 待发货(20) → 已发货(30) → 租赁中(40) → 归还中(50) → 验收中(60) → 已完成(70)
    │           │
    └───────────┴──→ 已取消(80)
验收中(60) 验收不通过 → 定损流程【二期预留】
```

### 3.2 设备状态（t_device.status）

```
在库(1) → 锁定(2) → 在租(3) → 归还验收中(6) → 在库(1)
  ↑           │        │ │
  │    订单取消│        │ └─→ 维修(4) → 在库(1)
  ←───────────┘        │        └─→ 报废(5)（修不好，终态）
  ←────────────────────┴─→ 报废(5)（灭失/严重损坏，终态）
```

## 4. 核心实体关系（ER 概览）

```
t_category 1 ──── n t_product（SPU）
t_product  1 ──── n t_product_sku ── 1 ──── n t_rental_plan（日/周/月/季方案）
t_product  1 ──── n t_product_param
t_product_sku 1 ─ n t_device（SN，一台一行）
t_device   1 ──── n t_device_check_report / t_device_repair
t_user 1 ──── n t_order ──── 1 t_order_item（一期单 SKU；明细行锁定具体 device_id）
t_order 1 ─── n t_lease（初始租期 + 续租段）/ t_deposit_record / t_bill /
                  t_logistics / t_payment_record
t_admin_user n ─ n t_role n ─ n t_permission
t_ai_conversation 1 ─ n t_ai_message
```

## 5. 各域设计说明与 DDL 索引

> 完整可执行 DDL 见 `sql/建表/01~08_*.sql`（含全部字段、注释、索引），本节记录设计意图与关键决策。

### 5.1 用户域（2 张）→ `sql/建表/01_用户域.sql`

| 表 | 设计要点 |
|----|---------|
| `t_user` | `wx_openid` / `ali_openid` / `phone` 三列各自唯一索引（可空，MySQL 允许多 NULL）——手机号绑定是跨端账号合并的锚点；实名/信用字段预留（二期信用免押） |
| `t_user_address` | 常规地址簿；`is_default` 每用户至多一条（业务层保证） |

### 5.2 商品域（5 张）→ `sql/建表/02_商品域.sql`

| 表 | 设计要点 |
|----|---------|
| `t_category` | 两级树（`parent_id`，0=顶级），如 摄像机→微单相机 |
| `t_product` | SPU，挂品牌/主图/图集/富文本详情；新建默认下架 |
| `t_product_sku` | 规格行；押金、买断价（预留）挂 SKU；**可租数量不冗余**，运行时按 `t_device(sku_id, status=1在库)` 统计 |
| `t_rental_plan` | 一 SKU 多方案（日/周/月/季），`min_days` 起租天数 |
| `t_product_param` | 键值对参数挂 SPU（不做参数模板，YAGNI） |

### 5.3 设备资产域（3 张）→ `sql/建表/03_设备资产域.sql`

| 表 | 设计要点 |
|----|---------|
| `t_device` | **一台实机一行**；平台资产编号 `device_no`（Z 前缀，二维码标签）与厂商 `sn` 分离；`idx_sku_status` 支撑 SKU 可租数量统计；成色定级冗余在行上，验收后回写 |
| `t_device_check_report` | 入库质检与归还验收共表（`type` 区分），归还验收带 `order_no`；结论：外观 + 功能 + 成色 + 照片附件 |
| `t_device_repair` | 维修记录；`cost_bearer` 费用承担（平台/用户）为二期定损预留 |

### 5.4 订单域（5 张）→ `sql/建表/04_订单域.sql`

| 表 | 设计要点 |
|----|---------|
| `t_order` | 主表含**全量快照**：收货人三件套 + 单价快照 `unit_price` + 计费单位 + 租期天数；金额拆分 `total_rent` / `deposit_amount` / `pay_amount` / `freight`；订单状态用 10~80 间隔枚举留扩展 |
| `t_order_item` | 一行一设备（无 quantity 字段）；`device_id` 建索引支持设备反查在租订单；商品/规格/单价/押金四类快照防改价改图影响历史单 |
| `t_lease` | 租约分段：初始租期 type=1，续租段 type=2（预留）；实际租期以此表为准，主表 `rent_end_date` 仅为展示 |
| `t_deposit_record` | 押金收取/退还/扣除全流水；`channel` 预留支付宝信用免押 |
| `t_bill` | 一期租金一次性支付=一条账单；周期付（二期）在此表按周期生成 |

### 5.5 支付域（1 张）→ `sql/建表/05_支付域.sql`

| 表 | 设计要点 |
|----|---------|
| `t_payment_record` | 渠道无关：`channel`（模拟/支付宝/微信预留）+ `biz_type`（租金/押金冻结）；模拟渠道 `channel_trade_no` 为空；回调统一入口按 `payment_no` 定位 |

### 5.6 物流域（1 张）→ `sql/建表/06_物流域.sql`

| 表 | 设计要点 |
|----|---------|
| `t_logistics` | `type` 区分发货寄出/归还寄回（一订单多段）；一期状态运营手动维护（已发出/已签收） |

### 5.7 AI 域（3 张）→ `sql/建表/07_AI域.sql`

| 表 | 设计要点 |
|----|---------|
| `t_ai_knowledge_doc` | 知识库**源数据**（FAQ/设备文档/租赁规则）；向量存 VectorStore（一期 SimpleVectorStore 内存，pgvector 规划预留），`content` 为重建依据，`status` 标记向量化进度 |
| `t_ai_conversation` | `conversation_id`（UUID）透传 spring-ai ChatMemory，用户维度 |
| `t_ai_message` | 会话记录审计（user/assistant/system） |

### 5.8 后台权限域（6 张）→ `sql/建表/08_后台权限域.sql`

| 表 | 设计要点 |
|----|---------|
| `t_admin_user` | bcrypt 密码；与 C 端 `t_user` 完全隔离 |
| `t_role` / `t_admin_user_role` / `t_permission` / `t_role_permission` | 标准 RBAC；权限树三级（目录/菜单/按钮），`permission_code` 唯一（按钮/接口鉴权用，目录菜单可空） |
| `t_operate_log` | 只增不改：仅 `create_time`，无逻辑删除（约定例外） |

## 6. 初始化数据

- 品类种子数据、超管账号、角色、权限菜单树：**M2 工程搭建时随前端菜单定稿一起产出**（`sql/初始化/`），密码 bcrypt 哈希由应用启动初始化生成，不在 SQL 中硬编码

## 7. 预留字段清单（二期不改动表结构）

| 字段 | 表 | 用途 |
|------|-----|------|
| `real_name` / `id_card_no` / `credit_status` | `t_user` | 芝麻信用免押 |
| `buyout_price` | `t_product_sku` | 以租代购买断 |
| `t_lease.type=2` | `t_lease` | 续租 |
| `t_deposit_record.type=3` | `t_deposit_record` | 定损扣款 |
| `t_bill.type=3/4` | `t_bill` | 买断差额/维修费账单 |
| `t_payment_record.channel=2/3` | `t_payment_record` | 支付宝/微信真实支付 |
| `t_device_repair.cost_bearer` | `t_device_repair` | 定损费用承担 |

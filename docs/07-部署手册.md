# 07-部署手册（ezu 单机 Docker Compose 部署）

> 适用：一台 2核4G 以上的 Linux 云服务器（Ubuntu 22.04 / Debian 12 / CentOS Stream 均可）。
> 架构：nginx(80/443) → app(Spring Boot :9000, JDK21) + MySQL 8 + Redis 7，全部容器化；
> B 端后台（ezu-console）静态托管在 nginx；小程序发布走微信平台不需要服务器。
> 规划预留：pgvector（M4 二期）以注释服务预留。

## 1. 部署总览

```
微信小程序 ──https──┐
H5(可选) ───────────┤
                    ▼
        nginx :80/:443（容器）
        ├── /console/  → ezu-console 静态文件（B 端后台）
        ├── /h5/       → ezu-miniapp H5 构建产物（可选）
        ├── /api/      → proxy_pass → app:9000（普通接口）
        └── /api/app/ai/ → proxy_pass → app:9000（SSE 流式，关缓冲）
                             │
                app 容器（ezu-startup fat jar, JRE21）
                 ├── ezu-mysql 容器（MySQL 8，仅容器网络可见）
                 └── ezu-redis 容器（Redis 7，仅容器网络可见）
```

**端口暴露原则**：只对外开放 80/443（和 SSH 的 22）。MySQL 3306、Redis 6379、应用 9000 一律不暴露到公网，运维时通过 `docker exec` 或绑 127.0.0.1 访问。

## 2. 服务器初始化

### 2.1 云控制台安全组

| 端口 | 来源 | 用途 |
|---|---|---|
| 22 | 你的 IP | SSH |
| 80 | 0.0.0.0/0 | HTTP（重定向 443 + 证书续签） |
| 443 | 0.0.0.0/0 | HTTPS |

**不要**放行 3306 / 6379 / 9000。

### 2.2 目录规划

```bash
sudo mkdir -p /opt/ezu/{app,sql,nginx/conf,nginx/certs,nginx/html/console,nginx/html/h5,data/mysql,data/redis}
sudo chown -R $USER /opt/ezu
```

```
/opt/ezu/
├── docker-compose.yml
├── .env                      # 环境变量（数据库密码、智谱 Key）
├── app/ezu-startup.jar       # 后端 fat jar
├── sql/                      # sql/建表/*.sql（首次初始化自动导入）
├── nginx/
│   ├── conf/ezu.conf
│   ├── certs/                # SSL 证书（fullchain.pem / privkey.pem）
│   └── html/{console,h5}/    # 前端构建产物
└── data/{mysql,redis}/       # 持久化数据（volume）
```

## 3. 安装 Docker 与 Compose

```bash
# 国内服务器用阿里云镜像安装（官方脚本替换一步）
curl -fsSL https://get.docker.com -o get-docker.sh && sudo sh get-docker.sh --mirror Aliyun

# 验证（Compose v2 已内置为子命令）

```

```json
{
  "registry-mirrors": ["https://docker.m.daocloud.io"]

```

```bash
sudo systemctl restart docker
```

## 4. docker-compose.yml

`/opt/ezu/docker-compose.yml`：

```yaml
name: ezu

services:
  mysql:
    image: mysql:8.0
    container_name: ezu-mysql
    restart: unless-stopped
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ezu                       # 自动建库
      TZ: Asia/Shanghai
    command:
      - --character-set-server=utf8mb4
      - --collation-server=utf8mb4_general_ci
      - --default-time-zone=+08:00
    volumes:
      - ./data/mysql:/var/lib/mysql
      # 首次启动自动按文件名顺序导入建表脚本（仅空库时执行）
      - ./sql:/docker-entrypoint-initdb.d:ro
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "127.0.0.1", "-p${MYSQL_ROOT_PASSWORD}"]
      interval: 5s
      timeout: 3s
      retries: 20
    # 不发布端口：仅容器网络内可达（临时排查可改 "127.0.0.1:3306:3306"）

  redis:
    image: redis:7-alpine
    container_name: ezu-redis
    restart: unless-stopped
    command: ["redis-server", "--appendonly", "yes"]
    volumes:
      - ./data/redis:/data
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 5s
      timeout: 3s
      retries: 20

  app:
    image: eclipse-temurin:21-jre
    container_name: ezu-app
    restart: unless-stopped
    working_dir: /app
    command: sh -c "java $JAVA_OPTS -jar /app/ezu-startup.jar"
    environment:
      TZ: Asia/Shanghai
      # —— 覆盖 application.yml 的连接地址（容器内按服务名访问）——
      SPRING_DATASOURCE_URL: jdbc:mysql://mysql:3306/ezu?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
      SPRING_DATASOURCE_USERNAME: root
      SPRING_DATASOURCE_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      SPRING_DATA_REDIS_HOST: redis
      SPRING_DATA_REDIS_PORT: "6379"
      # —— M4 启用：智谱 GLM（不设置则 AI 功能不可用，不影响启动）——
      ZHIPU_API_KEY: ${ZHIPU_API_KEY:-}
    volumes:
      - ./app/ezu-startup.jar:/app/ezu-startup.jar:ro
    depends_on:
      mysql:
        condition: service_healthy
      redis:
        condition: service_healthy

  nginx:
    image: nginx:1.27-alpine
    container_name: ezu-nginx
    restart: unless-stopped
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx/conf/ezu.conf:/etc/nginx/conf.d/default.conf:ro
      - ./nginx/certs:/etc/nginx/certs:ro
      - ./nginx/html:/usr/share/nginx/html:ro
    depends_on:
      - app

  # —— M4 二期规划预留：向量库（当前注释，启用需配套 SPRING_AI 配置）——
  # pgvector:
  #   image: pgvector/pgvector:pg16
  #   container_name: ezu-pgvector
  #   restart: unless-stopped
  #   environment:
  #     POSTGRES_PASSWORD: ${PG_PASSWORD}
  #     POSTGRES_DB: ezu
  #   volumes:
  #     - ./data/pgvector:/var/lib/postgresql/data
```

`/opt/ezu/.env`（与 compose 同目录；**此文件权限设 600，不进 git**）：

```bash
MYSQL_ROOT_PASSWORD=换成强密码
# M4 启用时填（https://open.bigmodel.cn 控制台创建）
ZHIPU_API_KEY=
```

> 内存参考（2核4G）：app 堆 768M + mysql ~500M + redis ~50M + nginx ~20M + 系统 ~600M，够用。
> 4G 以下机器建议在 `.env` 同级追加 `JAVA_OPTS=-Xmx768m`（compose 的 app.environment 已引用 `$JAVA_OPTS`，缺省为空即 JVM 默认）。

## 5. MySQL 初始化

把仓库 `sql/建表/` 下 8 个脚本原样上传：

```bash
# 本地执行（PowerShell/Git Bash 均可）
scp -r D:/project/ezu/sql/建表/*.sql root@服务器IP:/opt/ezu/sql/
```

**首次** `docker compose up -d mysql` 时，MySQL 会自动按文件名顺序（01→08）导入到 `ezu` 库——脚本本身是 `DROP TABLE IF EXISTS` + `CREATE`，幂等；但 initdb.d **只在数据目录为空时执行一次**。

后台超管账号无需 SQL：应用首次启动时 `AdminInitializer` 自动创建 `admin / admin123`（登录后台后立即改密）。

手动补导/校验：

```bash
# 手动导入（如表结构升级后重放单个脚本，先确认脚本含 DROP TABLE）
docker exec -i ezu-mysql mysql -uroot -p"$MYSQL_ROOT_PASSWORD" ezu < /opt/ezu/sql/04_订单域.sql

# 验证
docker exec ezu-mysql mysql -uroot -p"$MYSQL_ROOT_PASSWORD" -e "show tables" ezu
```

## 6. 后端构建与上传

本地（Windows，项目根 `D:\project\ezu`）：

```bash
mvn -pl ezu-startup -am clean package -DskipTests
# 产物：ezu-startup/target/ezu-startup-<version>.jar
scp ezu-startup/target/ezu-startup-*.jar root@服务器IP:/opt/ezu/app/ezu-startup.jar
```

> jar 固定命名为 `ezu-startup.jar`（compose 挂载该名字，避免版本号变动改配置）。

服务器上首次启动：

```bash
cd /opt/ezu
docker compose up -d          # mysql 建库导表 → app 启动 → nginx 就绪
docker compose logs -f app    # 看到 Spring 启动完成、AdminInitializer 初始化日志即可 Ctrl+C
```

冒烟验证：

```bash
# 服务器本机
curl http://127.0.0.1/api/app/auth/login -X POST -H 'Content-Type: application/json' -d '{"channel":1,"code":"smoke"}'
# 期望：HTTP 200 + {code:200,...,data:{token:...}}（mock 登录任意 code 可换 token）
```

## 7. 前端构建与上传

### 7.1 B 端后台 ezu-console

1. 改 `ezu-console/.env.prod`（**当前是模板默认值，必须改**）：

```bash
# 同域部署（推荐，nginx 同域反代 /api，无 CORS 问题）
VITE_SERVICE_BASE_URL=/

# 或独立 API 域名部署（需在 nginx 加 CORS 头）
# VITE_SERVICE_BASE_URL=https://api.yourdomain.com
```

2. 构建上传：

```bash
cd ezu-console
pnpm install
pnpm build
scp -r dist/* root@服务器IP:/opt/ezu/nginx/html/console/
```

登录：`https://yourdomain.com/console/`，账号 `admin / admin123`（**首次登录后改密**）。

### 7.2 C 端 H5（可选）

```bash
cd ezu-miniapp
npm run build:h5
scp -r dist/build/h5/* root@服务器IP:/opt/ezu/nginx/html/h5/
```

### 7.3 小程序（mp-weixin）

小程序不走服务器静态托管，但**正式包必须连 https 域名**：

1. 改 `ezu-miniapp/src/config/index.ts` 非 H5 分支的 `BASE_URL`：`http://localhost:9000` → `https://yourdomain.com`；
2. `npm run build:mp-weixin` → 微信开发者工具导入 `dist/build/mp-weixin` 上传审核；
3. 微信公众平台「开发管理 → 服务器域名 → request 合法域名」添加 `https://yourdomain.com`（要求：已备案 + HTTPS）。

## 8. nginx 配置

`/opt/ezu/nginx/conf/ezu.conf`：

```nginx
# HTTP → HTTPS（另用于 certbot 续签）
server {
    listen 80;
    server_name yourdomain.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    http2 on;
    server_name yourdomain.com;

    ssl_certificate     /etc/nginx/certs/fullchain.pem;
    ssl_certificate_key /etc/nginx/certs/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;

    # —— 通用 ——
    client_max_body_size 20m;          # 知识库文档上传（M4 B 端）
    gzip on;
    gzip_types text/css application/javascript application/json;

    # —— B 端后台（console）——
    location /console/ {
        alias /usr/share/nginx/html/console/;
        index index.html;
        try_files $uri $uri/ /console/index.html;   # history 路由回退
    }
    # 根路径跳转后台（可改为 H5）
    location = / { return 302 /console/; }

    # —— C 端 H5（可选）——
    location /h5/ {
        alias /usr/share/nginx/html/h5/;
        index index.html;
        try_files $uri $uri/ /h5/index.html;
    }

    # —— AI 聊天 SSE（更长前缀优先匹配；M4 启用，先配好）——
    location /api/app/ai/ {
        proxy_pass http://app:9000;
        proxy_http_version 1.1;
        proxy_set_header Connection "";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        proxy_buffering off;             # 核心：token 逐个下发，不攒批
        proxy_cache off;
        gzip off;                        # 防全局 gzip 攒 buffer
        add_header X-Accel-Buffering no;

        proxy_read_timeout 300s;         # AI 生成慢，放宽
        proxy_send_timeout 300s;
    }

    # —— 普通接口 ——
    location /api/ {
        proxy_pass http://app:9000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 60s;
    }
}
```

注意 `proxy_pass http://app:9000` 用的是 **compose 服务名**（容器网络内 DNS），不是 127.0.0.1。

改配置后：`docker compose exec nginx nginx -t && docker compose restart nginx`

### SSL 证书

方式任选：

- **云厂商免费证书**（阿里云/腾讯云每年 20 张免费 DV 证书）：下载 nginx 格式，`fullchain.pem`/`privkey.pem` 放 `/opt/ezu/nginx/certs/`；
- **Let's Encrypt**（DNS 校验或 standalone 模式签发后同样放 certs 目录，90 天需续）。

域名必须完成 **ICP 备案**（小程序 request 合法域名的硬性要求，提前 1~2 周办）。

## 9. 日常运维

```bash
cd /opt/ezu

# 状态/日志
docker compose ps
docker compose logs -f app            # 后端日志（tail -f）
docker compose logs --since 10m nginx

# 发布新版本后端（本地打完包 scp 覆盖 /opt/ezu/app/ezu-startup.jar 后）
docker compose restart app

# 发布前端（scp 覆盖 html 目录即可，无需重启）
# 仅 nginx 配置变更时：
docker compose exec nginx nginx -t && docker compose restart nginx

# 数据库备份（cron：每天 3:00 备份，保留 7 天）
# crontab -e 添加：
# 0 3 * * * docker exec ezu-mysql sh -c 'mysqldump -uroot -p"$MYSQL_ROOT_PASSWORD" ezu' | gzip > /opt/ezu/backup/ezu-$(date +\%F).sql.gz && find /opt/ezu/backup -mtime +7 -delete
# （需先 mkdir -p /opt/ezu/backup；MYSQL_ROOT_PASSWORD 需在容器 env 中，可改用 docker exec ezu-mysql printenv）

# 进入容器排查
docker exec -it ezu-mysql mysql -uroot -p ezu
docker exec -it ezu-redis redis-cli
```

## 11. 已知踩坑

| 症状 | 原因/解法 |
|---|---|
| mysql 容器反复重启 | `.env` 未创建或密码含 `$` 未转义（compose 会做变量替换） |
| 建表脚本没自动执行 | initdb.d 只在**空数据目录**执行一次；`rm -rf data/mysql/*` 后重新 up（会清库，慎用） |
| 接口 502 | app 未就绪或挂了：`docker compose logs app`；healthcheck 未配 app，首次启动慢属正常 |
| AI 回复卡住最后一次性吐出 | SSE location 的 `proxy_buffering off` / `gzip off` 没配 |
| 小程序真机请求失败 | 合法域名没配 / 域名未备案 / 证书链不全（用 fullchain 而非单独 cert） |
| console 刷新 404 | history 路由 `try_files` 回退没配 |
| 时区差 8 小时 | compose 各容器已加 `TZ=Asia/Shanghai`，宿主机也执行 `timedatectl set-timezone Asia/Shanghai` |

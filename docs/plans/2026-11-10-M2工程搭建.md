# M2 工程搭建实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 搭建易租（ezu）三端可运行空骨架——后端 8 模块 Maven 工程 + uni-app 小程序 + soybean-admin 管理后台 + docker-compose。

**Architecture:** Maven 多模块单体（ezu-startup 唯一可运行模块，聚合 6 业务模块 + common 基建）；骨架阶段无业务逻辑，验证以编译通过为准；spring-ai 依赖与 pgvector 以注释预留（M4/规划期启用）。

**Tech Stack:** JDK 21 / Spring Boot 4.1.0（`spring-boot-starter-webmvc`）/ MyBatis-Plus `mybatis-plus-spring-boot4-starter` 3.5.18 / Sa-Token `sa-token-spring-boot4-starter` 1.46.0 / spring-ai-bom 2.0.1（注释预留）/ uni-app Vue3+TS / soybean-admin（pnpm）

**已验证版本事实**（2026-11 检索）：MyBatis-Plus 3.5.13+ 新增 boot4 starter（最新 3.5.18）；Sa-Token 1.45.0 正式支持 Boot 4（最新 1.46.0）；Boot 4 的 web starter 更名为 `spring-boot-starter-webmvc`（ai-agent-lab 实证）。

**本机环境注意**：JAVA_HOME 默认指向 jdk17，编译需 `JAVA_HOME="D:\tool\jdk21"`；mvn 加 `MAVEN_OPTS="-Xmx768m -XX:MaxMetaspaceSize=384m"` 防 OOM；node v24 + npm 11 已装，pnpm 未装。

`ResultCode.java`：

```java
package com.ezu.common.response;

/**
 * 全局响应码（业务异常 HTTP 一律返回 200，以 code 判断成败）
 */
public interface ResultCode {

    int SUCCESS = 200;
    int PARAM_ERROR = 400;
    int UNAUTHORIZED = 401;
    int FORBIDDEN = 403;
    int SYSTEM_ERROR = 500;
}
```

`ResultData.java`：

```java
package com.ezu.common.response;

import lombok.Data;

/**
 * 统一响应信封
 */
@Data
public class ResultData<T> {

    private int code;
    private String msg;
    private T data;

    public static <T> ResultData<T> success(T data) {
        ResultData<T> result = new ResultData<>();
        result.code = ResultCode.SUCCESS;
        result.msg = "success";
        result.data = data;
        return result;
    }

    public static <T> ResultData<T> fail(int code, String msg) {
        ResultData<T> result = new ResultData<>();
        result.code = code;
        result.msg = msg;
        return result;
    }

    public boolean isSuccess() {
        return this.code == ResultCode.SUCCESS;
    }
}
```

`GlobalExceptionHandler.java`：

```java
package com.ezu.common.exception;

import cn.dev33.satoken.exception.NotLoginException;
import com.ezu.common.response.ResultCode;
import com.ezu.common.response.ResultData;
import lombok.extern.slf4j.Slf4j;
import org.springframework.validation.BindException;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

/**
 * 全局异常处理：业务异常 HTTP 一律 200 + 错误 code
 */
@Slf4j
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BusinessException.class)
    public ResultData<Void> handleBusiness(BusinessException e) {
        log.warn("业务异常: {}", e.getMessage());
        return ResultData.fail(e.getCode(), e.getMessage());
    }

    @ExceptionHandler(NotLoginException.class)
    public ResultData<Void> handleNotLogin(NotLoginException e) {
        return ResultData.fail(ResultCode.UNAUTHORIZED, "未登录或登录已过期");
    }

    @ExceptionHandler({MethodArgumentNotValidException.class, BindException.class})
    public ResultData<Void> handleValid(BindException e) {
        String msg = e.getBindingResult().getFieldErrors().isEmpty()
                ? "参数校验失败"
                : e.getBindingResult().getFieldErrors().get(0).getDefaultMessage();
        return ResultData.fail(ResultCode.PARAM_ERROR, msg);
    }

    @ExceptionHandler(Exception.class)
    public ResultData<Void> handleException(Exception e) {
        log.error("系统异常", e);
        return ResultData.fail(ResultCode.SYSTEM_ERROR, "系统繁忙，请稍后重试");
    }
}
```

```java
package com.ezu.common.entity;

import com.baomidou.mybatisplus.annotation.FieldFill;
import com.baomidou.mybatisplus.annotation.IdType;
import com.baomidou.mybatisplus.annotation.TableField;
import com.baomidou.mybatisplus.annotation.TableId;
import com.baomidou.mybatisplus.annotation.TableLogic;
import lombok.Data;

import java.time.LocalDateTime;

/**
 * 实体基类：雪花ID + 审计字段 + 逻辑删除（0=未删除，1=已删除）
 */
@Data
public abstract class BaseEntity {

    @TableId(type = IdType.ASSIGN_ID)
    private Long id;

    @TableField(fill = FieldFill.INSERT)
    private LocalDateTime createTime;

    @TableField(fill = FieldFill.INSERT_UPDATE)
    private LocalDateTime updateTime;

    @TableField(fill = FieldFill.INSERT)
    private Long createBy;

    @TableField(fill = FieldFill.INSERT_UPDATE)
    private Long updateBy;

    @TableLogic
    @TableField("is_deleted")
    private Integer isDeleted;
}
```

```java
package com.ezu.common.entity;

import com.baomidou.mybatisplus.core.handlers.MetaObjectHandler;
import org.apache.ibatis.reflection.MetaObject;
import org.springframework.stereotype.Component;

import java.time.LocalDateTime;

/**
 * 审计字段自动填充（操作人登录体系就绪后在此补充）
 */
@Component
public class MyMetaObjectHandler implements MetaObjectHandler {

    @Override
    public void insertFill(MetaObject metaObject) {
        this.strictInsertFill(metaObject, "createTime", LocalDateTime.class, LocalDateTime.now());
        this.strictInsertFill(metaObject, "updateTime", LocalDateTime.class, LocalDateTime.now());
    }

    @Override
    public void updateFill(MetaObject metaObject) {
        this.strictUpdateFill(metaObject, "updateTime", LocalDateTime.class, LocalDateTime.now());
    }
}
```

```java
public class SaTokenConfigure implements WebMvcConfigurer {

    @Override
    public void addInterceptors(InterceptorRegistry registry) {

                        .match("/api/**")
                        .notMatch("/api/app/auth/**", "/api/admin/auth/**", "/api/callback/**")
                        .check(r -> StpUtil.checkLogin())))
                .addPathPatterns("/**");
    }
}
```

# M3a 后端核心闭环 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 打通租赁核心闭环的全部后端接口——双账号登录（C 端 mock / B 端 RBAC）→ 商品（品类/SPU/SKU/租金方案）→ 设备（SN 台账/入库/质检/维修/报废）→ 订单（试算/下单/支付/发货/收货/归还/验收/押金）→ Mock 支付渠道抽象。

**Architecture:** 分层 `Controller → ApplicationService → DomainService → Repository(ServiceImpl) → Mapper`，模块间依赖单向：`ezu-payment → ezu-order → ezu-product → ezu-common`，`ezu-admin/ezu-user → ezu-common`。Sa-Token 多账号体系（loginType=`user`/`admin`）。设备即库存：可租数量运行时统计 `t_device(sku_id,status=1)`，下单用条件 UPDATE 做 CAS 锁定。

**Tech Stack:** Spring Boot 4.1 / MyBatis-Plus 3.5.18 / Sa-Token 1.46（sa-token-redis-template）/ Redis（单号自增）/ spring-security-crypto（仅 BCrypt）。

**DDL 是唯一字段权威来源：** `sql/建表/01~08_*.sql`。实体字段与 DDL 一一映射（下划线→驼峰），本计划不重复罗列字段，实现时以 DDL 为准。

**运行环境说明（重要）：** 本机无 docker，MySQL/Redis 由用户自行提供（localhost:3306 / 6379，见 ezu-startup/application.yml）。AI 侧验证 = **编译 + 代码评审**；运行时冒烟由用户执行，验证命令在文末「验收清单」。

## 全局约定（所有任务共同遵守）

### 包结构（每模块内，M2 已建空目录）

```
com.ezu.{module}
├── api                 # Controller（@RestController，路径 /api/app/** 或 /api/admin/**）
├── application         # ApplicationService（业务编排、@Transactional）
├── domainService       # DomainService 接口 + impl（核心业务逻辑、跨表）
├── domain              # entity / req / vo / enums（子包）
└── repository          # Repository extends ServiceImpl<Mapper, Entity> + repository.mapper
resources/mapper/{module}/   # XML（本计划全部用 MP lambdaQuery，无需 XML）
```

### 实体规则

- 实体 `extends BaseEntity`（已有：id/createTime/updateTime/createBy/updateBy/isDeleted），只写业务字段
- `@TableName("t_xxx")`；时间字段 `LocalDate`/`LocalDateTime`；金额 `BigDecimal`；状态 `Integer`
- 枚举放 `domain/enums`，**常量类形式**（本计划统一用 `public interface XxxStatus { int XX = n; }` 或 final class + 常量，见 T4 示例），注释标注所有值含义（前端依赖）

### 接口规则（沿用 04-API规范）

- 查询：`POST` + Req extends `PageQuery` → `PageVo<T>`；详情 `GET /{no或id}`
- 新增/修改复用 save（id 空=新增）；删除/上下架等批量 → `BatchOperateResultVo`（T1 新建）
- 统一返回 `ResultData<T>`（success/fail 已有）；业务异常 `throw new BusinessException("xxx【{}】不存在", arg)`
- 单号交互：对外用 orderNo/productNo 等，不暴露数据库 ID（但 GET /{id} 详情用 ID 的商品例外——商品无单号交互约定，SPU 详情用 id；订单/设备/支付一律单号）
- Req 校验：jakarta.validation，`@NotBlank/@NotNull` + `@Size`，Controller 类上 `@Validated`
- 写接口（下单/支付/发货/验收等状态流转类）不要求 @RepeatSubmit（ezu-common 暂无该注解，M3 不引入）

- [ ] **Step 1: NoGenerator**（单号规则见 03-数据库设计 §2：`前缀 + yyyyMMdd + 4位流水`，Redis 自增）

```java
package com.ezu.common.util;

import lombok.RequiredArgsConstructor;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.stereotype.Component;

import java.time.LocalDate;
import java.time.format.DateTimeFormatter;

/**
 * 业务单号生成器：前缀 + yyyyMMdd + 4位流水（Redis 自增，key 当日过期）
 * 前缀：R订单 G商品 S SKU Z设备 B账单 P支付 D押金
 */
@Component
@RequiredArgsConstructor
public class NoGenerator {

    private static final DateTimeFormatter FMT = DateTimeFormatter.ofPattern("yyyyMMdd");

    private final StringRedisTemplate stringRedisTemplate;

    public String next(String prefix) {
        String date = LocalDate.now().format(FMT);
        String key = "ezu:no:" + prefix + ":" + date;
        Long seq = stringRedisTemplate.opsForValue().increment(key);
        stringRedisTemplate.expire(key, java.time.Duration.ofHours(25));
        return prefix + date + String.format("%04d", seq);
    }
}
```

```java
package com.ezu.startup.config;

import cn.dev33.satoken.interceptor.SaInterceptor;
import cn.dev33.satoken.router.SaRouter;
import com.ezu.common.satoken.StpAdminUtil;
import com.ezu.common.satoken.StpUserUtil;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.servlet.config.annotation.InterceptorRegistry;
import org.springframework.web.servlet.config.annotation.WebMvcConfigurer;

/**
 * Sa-Token 拦截配置：C 端 /api/app/** 校验 user 账号，B 端 /api/admin/** 校验 admin 账号，白名单放行
 */
@Configuration
public class SaTokenConfigure implements WebMvcConfigurer {

    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(new SaInterceptor(handle -> {
                    SaRouter.match("/api/app/**")
                            .notMatch("/api/app/auth/**")
                            .check(r -> StpUserUtil.checkLogin());
                    SaRouter.match("/api/admin/**")
                            .notMatch("/api/admin/auth/**")
                            .check(r -> StpAdminUtil.checkLogin());
                }))
                .addPathPatterns("/api/**");
    }
}
```

**StpInterfaceImpl（sa-token 权限数据源，loginType 分流）：**

```java
package com.ezu.admin.satoken;

import cn.dev33.satoken.stp.StpInterface;
import com.ezu.admin.domainService.AdminUserDomainService;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Component;

import java.util.Collections;
import java.util.List;

/**
 * Sa-Token 权限数据源：admin 账号返回角色权限码；user 账号返回空（C 端无 RBAC）
 */
@Component
@RequiredArgsConstructor
public class StpInterfaceImpl implements StpInterface {

    private final AdminUserDomainService adminUserDomainService;

    @Override
    public List<String> getPermissionList(Object loginId, String loginType) {
        if ("admin".equals(loginType)) {
            return adminUserDomainService.getPermissionCodes(Long.valueOf(loginId.toString()));
        }
        return Collections.emptyList();
    }

    @Override
    public List<String> getRoleList(Object loginId, String loginType) {
        if ("admin".equals(loginType)) {
            return adminUserDomainService.getRoleCodes(Long.valueOf(loginId.toString()));
        }
        return Collections.emptyList();
    }
}
```

> getPermissionCodes 实现：`admin_user_role → role_id 集合 → role_permission → permission_id 集合 → permission 表取 permission_code 非空列表`（三步批量查，禁止循环查库）。

// com.ezu.admin.log.OperateLog
@Target(ElementType.METHOD) @Retention(RetentionPolicy.RUNTIME)
public @interface OperateLog {

**CAS 锁设备（DeviceDomainServiceImpl，防并发双租同一台）：**

```java
public Long lockDevice(Long skuId) {
    // 候选：取 5 台在库按 id 升序
    List<Device> candidates = repository.lambdaQuery()
            .eq(Device::getSkuId, skuId).eq(Device::getStatus, DeviceStatus.IN_STOCK)
            .orderByAsc(Device::getId).last("limit 5").list();
    // 竞态兜底：查不到再 count 总在库（含刚被锁的），为 0 抛「商品【{}】已无可租设备」
    for (Device d : candidates) {
        boolean ok = repository.lambdaUpdate()
                .eq(Device::getId, d.getId()).eq(Device::getStatus, DeviceStatus.IN_STOCK)
                .set(Device::getStatus, DeviceStatus.LOCKED).update();
        if (ok) { return d.getId(); }
    }
    throw new BusinessException("商品可租设备已被抢租，请重试");
}
```

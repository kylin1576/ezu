# 易租（ezu）开发计划

> 版本：v0.1（骨架）
> 日期：2026-11-10
> 状态：里程碑框架，任务随进度细化

---

## 里程碑

| 阶段 | 内容 | 产出 |
|------|------|------|
| M1 文档与建模 ✅ 完成（2026-11-10） | 评审 PRD/架构文档 → **数据库建模**（全量 DDL + sql/ 脚本）→ API 规范细化 | docs/ 定稿、sql/ 全量建表脚本 |
| M2 工程搭建 ✅ 完成（2026-11-10） | 后端 8 模块 Maven 骨架 + common 基建（统一响应/异常/Sa-Token 拦截器（双账号路由预留）/MyBatis-Plus 配置）；uni-app 小程序初始化；管理后台（soybean-admin）初始化；docker-compose | 三端可运行的空骨架 |
| M3 核心闭环 | 双账号登录（Sa-Token 多账号体系：用户/管理员）→ 商品（品类/SPU/SKU/租金方案）→ 设备（SN 台账/入库/质检）→ 订单（下单/模拟支付/发货/归还/验收/押金台账）→ 后台对应管理页 | 资产闭环可演示 |
| M4 AI 助手 | spring-ai 接入（chat/SSE）→ ChatMemory → tool calling（查商品/查订单）→ RAG（知识库管理 + SimpleVectorStore）| 小程序 AI 助手可用 |
| M5 打磨与预留 | 仪表盘、逾期标记、续租/买断入口（预留）、支付渠道接口预留注释、pgvector 注释预留 | 一期收尾 |

## 原则

- 每个里程碑完成即提交 git，可运行优先于完美
- 建模（M1 数据库设计）完成评审后才进入 M2 编码
- 二期（支付宝信用、定损理赔、营销、ChatBI）不在本计划内，仅保证接口/模型预留不堵路
